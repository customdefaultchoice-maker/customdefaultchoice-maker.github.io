# Ananta Wiki

Independent pre-release wiki covering ANANTA (Project Mugen) characters, Nova City, and release dates.

Ananta Wiki is a clean, community-driven encyclopedia for ANANTA (formerly Project Mugen), tracking official release dates, playable characters, factions, and open-world locations.

### Key Features

- **Character Dossiers**: Browse confirmed playable characters including Captain, Taffy, Richie, Lykaia, Seymour, Bansy, Alan, and Dila with faction and role notes.
- **World and Location Guides**: Explore Nova City neighborhoods, Chongxiao transit routes, exploration mechanics, and traversal systems.
- **Release Countdown and Fact-Checked Lore**: Stay up to date with the January 15, 2027 global launch target and curated trailer breakdowns.
- **Fast Mobile-Friendly Reference**: Clean navigation with zero clutter across desktop and mobile screens.
