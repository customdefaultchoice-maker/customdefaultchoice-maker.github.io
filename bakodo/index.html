Bakodo.jp — Free browser barcode generator supporting 111 formats including JAN, QR, Code 128, PNG/SVG, A4 sheets, and ZPL.

Bakodo.jp is a free online barcode generator with no signup required, supporting 111 barcode standards with PNG/SVG export, A4 label sheets, serial batches, and ZPL.

  • 111 Barcode Standards: JAN/EAN, QR Code, Code 128, UPC, ITF-14, Data Matrix, GS1
  • Vector SVG & PNG exports, A4 label sheets, serial batch generation, and Zebra ZPL output
  • Free browser workflow with zero signup required
